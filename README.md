
## Ejecutar el proyecto

Backend:

```bash
cd construccion2
./mvnw spring-boot:run
```

En Windows:

```bash
cd construccion2
.\mvnw.cmd spring-boot:run
```

Frontend:

```bash
cd react/frontend
npm install
npm run dev
```
